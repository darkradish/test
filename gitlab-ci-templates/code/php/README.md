## Description

Templates available and description :

| File         | Fonction         | Description                 |
| ------------ | ---------------- | --------------------------- |
| publish.yaml | publish:gitlab   | Publish artifacts on gitlab |
| install.yaml | install:composer | Run composer install        |

## publish.yaml

### publish:gitlab

The job push composer artifacts on the gitlab registry

Example usage :
```yaml
publish:gitlab:
    extends: .template:php:publish:gitlab
```

You will find your artifact in gitlab>project>Packages & Registries> Package Registry
with you tag or your branch

## install.yaml

### install:composer

Run composer install. You can choose which mode you want: prod or dev

With composer in prod mode, it adds specific option for production.

parameters :

| VARIABLE                   | DESCRIPTION                                                | DEFAULT VALUE             |
|----------------------------|------------------------------------------------------------|---------------------------|
| COMPOSER_DOCKER_IMAGE      | Composer image                                             | composer:2                |
| COMPOSER_VERSION           | Composer image version                                     | 2                         |
| COMPOSER_WITH_PROD_OPTIONS | Run composer with prod option or not. Choose true or false | false                     |
| COMPOSER_HOME              | Composer home directory                                    | $CI_PROJECT_DIR/.composer |
| COMPOSER_PROD_OPTIONS      | Specify options for composer in prod                       |                           |
| COMPOSER_OPTIONS           | Specify options for composer. For example, --no-scripts    |                           |

## test.yaml

### test:lint:phpcs

Check coding style. By default, it will lookup config file in this order `.phpcs.xml > phpcs.xml > .phpcs.xml.dist > phpcs.xml.dist`

See documentation https://github.com/squizlabs/PHP_CodeSniffer/wiki/Advanced-Usage#using-a-default-configuration-file

parameters :

| VARIABLE         | DESCRIPTION                                | DEFAULT VALUE                                      |
| ---------------- | ------------------------------------------ | -------------------------------------------------- |
| PHP_DOCKER_IMAGE | php image                                  | eu.gcr.io/digital-staging/bases/php:master-7.4-cli |
| PHP_VERSION      | php version. possible value are defined in | master-7.4-cli                                     |
